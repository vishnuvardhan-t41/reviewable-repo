The mental model

Context in. Typed decisions out.

Jev evaluates named questions against the same state in a single request. Your software receives answers in a predictable shape, then decides what to do with them.

01

Prepare the state

Share the relevant context: a ticket, message, order, incident, or structured record. Keep it focused on the decision.

02

Define questions

Ask specific questions and choose the answer type. Add options or an ordered rubric when the type needs them.

03

Read the results

Answers come back under the question names you chose, with probabilities and confidence fields where supported.

04

Apply your rules

Your application uses its own thresholds, permissions, and review paths to route, continue, or ask a person.

state+typed questions→Jev→answers→your application

From first try to integration

How to use Jev

Prototype the decision before you wire it into a product. Use real examples, including ambiguous cases, to see where the signal helps.

  1. 1Pick a bounded decision. Start with a workflow where the possible outcomes are known.
  2. 2Try it in the playground. Enter sample state, add questions, and inspect the response.
  3. 3Create an API key. Get access in your TypeSafe account and store the key in a server-side environment variable.
  4. 4Call the endpoint. Send a JSON request to POST https://api.typesafe.ai/v1/systemone with Bearer authentication.
  5. 5Connect results to your code. Set thresholds, fallback behavior, and human review according to your application’s policies.
A good division of work

Use Jev for the decision. Use code for the action.

Jev can provide a useful signal for routing, scoring, or review. Your application should validate the result and remain responsible for permissions, thresholds, and side effects.

When to reach for something else

For open-ended writing, detailed explanations, or multi-step plans, pair a decision model with a generative model that produces language. Jev’s focus is structured decisions.

A few useful boundaries

Good to know before you ship.

Is Jev a chat assistant?

Jev is designed to return structured decisions for software. It is not intended to replace a general-purpose model for open-ended conversation or writing.

Are probabilities guarantees?

No. Treat probabilities and confidence as signals to evaluate in your own workflow. Test on representative cases and decide how uncertain results should be handled.

Can one request ask multiple questions?

Yes. A request can include multiple named questions over the same state, and the response uses those names to match answers back to questions.

Where can I find the latest API details?

Check TypeSafe’s API reference for current authentication, model names, request fields, and response schemas. Product details can change over time.
